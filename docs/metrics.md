# 成长指标口径 v1

输入严格对应 A 的 `docs/data_dictionary.md` 五张表；计算模块不读数据库、不改原始数据。六维顺序固定为 academic、reading、sport、routine、consumption、diversity。分数限制在 0–100，展示保留两位小数，综合分使用展示维度分计算并保留两位小数。

| key / 名称 | 计算方法 | 权重 |
| --- | --- | --- |
| academic / 学业表现 | 各课程先取历史平均，再对课程等权平均（无学分字段，不声称学分加权） | 40% |
| reading / 阅读素养 | `min(累计借阅次数 / 12, 1) × 100` | 12% |
| sport / 运动健康 | `min(最近56天运动分钟 / 1200, 1) × 100`，即八周平均每周150分钟为满分参考 | 12% |
| routine / 作息规律 | `100 × (0.7 × 有早餐的消费日数 / 有消费日数 + 0.3 × (1 − 夜宵记录数 / 消费记录数))` | 12% |
| consumption / 消费理性 | `100 × 正餐、水果、日用品金额 / 全部消费金额`；仅是校园卡消费结构代理指标 | 12% |
| diversity / 生活丰富度 | `100 × (min(消费地点数/5,1) + min(消费品类数/5,1) + min(运动类型数/4,1)) / 3` | 12% |

12 次借阅、5 个地点、5 个品类、4 种运动均为课程展示参数，不是人群统计结论。累计指标受记录覆盖期影响，不适合跨年级直接排名。无心理、第二课堂数据，不推断心理健康或活动能力。餐次不能证明真实作息；消费结构不能证明财务能力，消费得分不使用贫富或绝对金额划分好坏。运动参考不构成个体健康评估。

只有参考日期及以前的记录参与计算：考试、借阅、消费、运动分别按各自日期过滤。尚未到归还日期的借阅仍计入借阅总量，但不参与 `avg_days`；仅平均已经归还的借阅时长。运动周范围为 `[as_of−55天, as_of]`，每7天一段，返回最早到最新的8段。

消费 `avg_daily` 分母为该学生第一笔至最后一笔消费的自然日数（含首尾、包括中间无消费日），不是在校天数。早餐率分母为有消费的不同日期数；夜宵率分母为消费笔数。空消费时两者均为0。`hourly` 按消费发生小时统计笔数。消费结构按品类汇总笔数及金额；金额按分累加，最终转为元。

缺失证据：学业没有成绩、阅读没有借阅、运动没有任何历史运动记录、作息/消费没有消费记录、丰富度没有消费和运动记录时，对应 key 加入 `missing_metrics`，维度显示0。运动有历史记录但近56天为0时是有证据的0分。综合分为 `sum(已有维度分 × 权重) / sum(已有维度权重)`。无任何证据时等级为 `暂无数据`，其余按优秀≥80、良好≥70、合格≥60、待提升<60。

标签只来自观测证据：学业≥80为“学业稳定”；借阅≥12为“阅读爱好者”；运动维度≥80为“运动达人”；早餐率≥0.6且夜宵率≤0.1为“晨型作息”。预警仅为教学核查提示：任一课程平均<60触发“学业预警”，有证据且综合分<60触发“综合分偏低”，最多两个原因。空数据不作为低分预警。群体均分只纳入有证据的学生，各维度均分只纳入该维度有证据的学生；人数仍包含无明细学生，预警人数等于同筛选条件的预警列表长度。
